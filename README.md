# Laundrify - Admin Dashboard

Aplikasi dashboard admin untuk sistem manajemen layanan laundry. Proyek ini berfokus pada pengembangan UI/UX halaman **"Ringkasan" (Overview)** dengan desain yang modern, minimalis, dan responsif.

## 🛠 Teknologi yang Digunakan
- **React.js** (v18)
- **CSS3** (CSS Variables untuk theming)
- **HTML5**

## ✨ Fitur Utama
- **Kartu Ringkasan:** Menampilkan Total Pesanan, Pendapatan, Pelanggan Baru, dan Layanan Aktif.
- **Visualisasi Data:** Grafik perbandingan pendapatan dan diagram status pesanan.
- **Manajemen Data:** Tabel pesanan terbaru, daftar layanan populer, dan aktivitas pelanggan.
- **Responsif:** Tampilan menyesuaikan dengan baik di Desktop, Tablet, dan Mobile.
